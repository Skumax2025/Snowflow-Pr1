# Структуры

## Суть
Точки интереса на глобальной карте мира: Посты, Базы, Склады, Ретрансляторы. Каждая — рядовая сущность по общему контракту [[Пулы событий]] (характеристики + собственный пул), без исключений вроде тех, что разрешены Городу. Дают миру физические источники радиосигналов и логистику: Посты — болтовню и сплетни, Базы — военные сигналы, Склады — конвои снабжения, Ретрансляторы — дальность связи. Единственная Структура с особым поведением сверх общего контракта — Склад: он порождает дочернюю сущность Конвой (полный механизм — в [[Пулы событий]]).

## Как работает
1. Каждая Структура — рядовая сущность по контракту [[Пулы событий]]: тикает собственный пул, сверяя момент со своим расписанием через [[Время]] (тик дёргает [[Игровой цикл]]), катает взвешенный выбор события, применяет эффект к себе, пишет факт в [[Журнал фактов]] с обязательным полем «место» = собственный квадрант.
2. Общая для всех четырёх типов характеристика — **Целостность** (0–100, роль HP). У каждого типа сверх неё своя доменная характеристика [нужно значение — состав].
3. Структуры принимают входящее явное событие **«атака силой N»** от пула [[Фракции]] (Противники) — без демпфера вроде Обороны: N сразу вычитается из Целостности. Кто именно получит конкретную атаку — решает не эта заметка: маршрутизация по квадранту описана в [[Фракции]], здесь только контракт приёма.
4. При Целостности = 0 Структура пишет факт «структура уничтожена» и перестаёт тикать — тем же способом, каким терминальное событие останавливает Конвой. Разрушение необратимо в рамках прототипа [допущение — ремонта Структур нет].
5. Склад дополнительно умеет через свой пул породить дочернюю сущность Конвой. Механизм целиком в [[Пулы событий]]; здесь только факт, что эта способность есть именно у Склада. Терминальные события Конвой шлёт [[Город]]у напрямую, Склад в этом не участвует.
6. Ретранслятор механически не отличается от остальных трёх. Его «особость» («тишина как ложь») эмерджентна: сводку о нём готовит [[Генератор эфира]] снимком на свой час, а слышимость обычных сигналов всегда считается по живому состоянию. Ретранслятор собственных фактов не генерирует. **Формула дальности связи живёт у [[Генератор эфира]]** («Радиус слышимости» по типу), здесь не решается.
7. Посты — рядовая сущность с чисто флейвор-пулом (болтовня, просьбы, сплетни), не вторая симуляция вышки игрока [допущение, исходя из рамок].
8. Базы и Фракция «Свои» разведены сознательно и окончательно: Базы — физическая инфраструктура (цель для атаки, имеет Целостность, может быть уничтожена), «Свои» — командование (голос в эфире, без Целостности, не цель).
9. У каждой Структуры есть адрес — квадрант, формат буква+цифра, канон [[Погода]]. Приходит из состава сценария в конфиге партии ([[Игровой цикл]]) при инициализации. Адрес уходит в поле «место» записи Журнала, в решение о слышимости у [[Генератор эфира]], в справочник имён [[Парсер]]а и в то, что сверяет игрок при [[Проверка сигнала]]. Это же поле «место» читают [[Фракции]] для выбора квадранта атаки.
10. Структуры не порождают других Структур и не порождаются в ходе партии — стартовый набор фиксирован при инициализации [допущение].

## Контракт
- **Вход:** тик собственного пула (дёргает [[Игровой цикл]], сверяется с [[Время]]); стартовые характеристики и квадрант из конфига партии; явное событие «атака силой N» от [[Фракции]], уже маршрутизированное на конкретную Структуру; для Склада — собственный внутренний триггер спавна Конвоя.
- **Выход:** факт в [[Журнал фактов]] на каждое сработавшее событие пула, включая «структура уничтожена»; изменения своих характеристик; состояние (тип, Целостность, квадрант) — по запросу [[Генератор эфира]] и [[Парсер]]у; для Склада — новая дочерняя сущность Конвой в собственном реестре.
- **Владеет:** своими характеристиками (Целостность + доменная); собственной таблицей пула; своим адресом; для Склада — реестром живых Конвоев.
- **Не знает:** о видимости в эфире, диапазонах и дальности связи (это [[Генератор эфира]]); о том, что написал игрок; о состоянии других Структур; о Городе напрямую — об исходе Конвоя Город узнаёт от самого Конвоя; о том, как [[Фракции]] выбирают цель атаки.

## Первый срез
Инициализировать один Склад стартовыми значениями и квадрантом [нужно значение]. Прислать «атака силой N» больше текущей Целостности → Целостность падает до 0 → в Журнал пишется факт «структура уничтожена» с полем «место» → Склад перестаёт тикать и больше не рожает конвои.

Признак готовности: атака гасит Структуру общим механизмом [[Пулы событий]], без ручного кода вне контракта. Откуда взялось событие — из [[Фракции]] по квадранту или как мок — для среза не важно.

## Связи
- [[Пулы событий]] — владеет общим контрактом; Склад дополнительно использует механизм спавна дочерних сущностей.
- [[Игровой цикл]] — инициализирует составом сценария, дёргает тик.
- [[Журнал фактов]] — шлёт факты с обязательным полем «место»; это же поле читает [[Фракции]].
- [[Время]] — читает момент партии для сверки расписания тика.
- [[Фракции]] — принимает маршрутизированное «атака силой N».
- [[Генератор эфира]] — отдаёт по запросу тип, Целостность и квадрант: для решения о слышимости и для сводки ретрансляторов.
- [[Парсер]] — отдаёт по запросу список живых структур с квадрантами для справочника имён.
- [[Город]] — не связаны напрямую: об исходе Конвоя Город узнаёт от самого Конвоя.

## Открытые вопросы
- Конкретные доменные характеристики и стартовые значения Целостности по каждому из 4 типов — контент.
- Полный список событий пула по каждому типу, кроме «родить конвой» у Склада — контент.
- Диапазон силы атаки N и способ вычитания — общий с [[Город]] и [[Фракции]].
- Есть ли у отдельных структур индивидуальные имена/номера («Склад №4») для справочника [[Парсер]]а и для сводки ретрансляторов, или всё оперирует типом и квадрантом.
