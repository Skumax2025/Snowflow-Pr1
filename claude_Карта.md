# Карта

## Суть
Блокнот игрока, а не окно в мир. Единственное место, где показания с радио (метеосводка, сводка ретрансляторов) превращаются в его собственную картину квадрантов — вручную, кликами, без автозаполнения. Карта не хранит правду о мире, она хранит то, что игрок сам решил запомнить. Ошибка при переносе — не баг интерфейса, а часть замысла: она даёт ту самую паранойю, вокруг которой строится петля правды (5.2 мастер-конспекта). Ядро всей игры лежит в зазоре между тем, что было на самом деле ([[Журнал фактов]]), и тем, что записано здесь.

## Как работает
1. Обе регулярные сводки приходят как **обычные пойманные сигналы**: [[Генератор эфира]] публикует их в эфире в свой час на фиксированной известной частоте, игрок ловит их попыткой настройки, и [[Приём сигнала]] шлёт сюда «сигнал_пойман» типа «сводка» с вложенным содержимым снимка. Не поймал (спал, был занят, шторм над вышкой) — сводка протухла по TTL, и картины за эти сутки просто нет. **[решено, аудит]**
2. Пойманная сводка отображается игроку как текст/список рядом с сеткой. Карта её не проверяет и не может проверить: снимок правдив на момент публикации, но к моменту прочтения мог устареть — на этом и стоит «тишина как ложь».
3. Игрок вручную переносит сводку на сетку: два клика — выбрать квадрант, выбрать тип и значение метки. Система ничего не подставляет сама.
4. **Метка шторма** — накопительная. Каждый клик добавляет новую запись `{квадрант, время_наблюдения, статус}` в историю этого квадранта, старые записи не стираются. Именно это позволяет игроку при [[Проверка сигнала]] самому сверить: «сигнал утверждает, что вышел из D4 шесть часов назад — а что я сам видел в D4 шесть часов назад».
5. **Метка ретранслятора** — перезаписываемая. Один клик — одно текущее значение (активен / мёртв / не знаю) на квадрант, старое теряется без следа. Важно только «жив ли он сейчас».
6. **Метка поста** — декоративная, без статуса. Игрок отмечает факт «здесь есть пост», это ориентир на сетке **[допущение — метки Постов нигде не читаются механически и, вероятно, не будут]**.
7. Ретрансляторы и Посты не подгружаются заранее ниоткуда — их существование и квадрант игрок узнаёт только из эфира. Карта никогда не читает [[Структуры]], [[Погода|Погоду]] или [[Журнал фактов]].
8. Раскрытые детали сигнала из [[Проверка сигнала]] на Карту не поступают событием. Хочет запомнить — переносит вручную тем же кликом. Отдельного стыка между системами нет.
9. Просмотр карты не тратит время **[принято]**.

## Контракт
- **Вход:** событие «сигнал_пойман» типа «сводка» (с вложенным содержимым) от [[Приём сигнала]]; действие игрока «поставить метку (квадрант, тип, значение)» — сырой клик; размер сетки из конфига партии ([[Игровой цикл]]); текущий момент от [[Время]] для штампа времени_наблюдения.
- **Выход:** ничего наружу. Тупиковый узел, как [[Газета]] — отдаёт своё содержимое только собственному интерфейсу.
- **Владеет:** сеткой квадрантов на своей стороне; историей меток шторма по каждому квадранту (ничего не удаляется в рамках партии); текущим статусом меток ретрансляторов; метками постов; последней пойманной сводкой каждого типа для отображения.
- **Не знает:** ничего о реальном состоянии [[Погода]], [[Структуры]] или [[Журнал фактов]] — не читает их и никогда не сверяет свои метки с правдой; о содержании рапорта и вердиктах [[Парсер]]а; о том, что показала [[Проверка сигнала]] — получает только то, что игрок сам кликнул.

## Данные

**Метка шторма** (список записей на квадрант):

| Поле | Тип | Комментарий |
| :--- | :--- | :--- |
| квадрант | буква+цифра | формат из [[Погода]] |
| время_наблюдения | игровое время на момент клика | читает у [[Время]] |
| статус | шторм / чисто | значение, которое выбрал игрок |

**Метка ретранслятора** (одна запись на квадрант, перезаписывается):

| Поле | Тип | Комментарий |
| :--- | :--- | :--- |
| квадрант | буква+цифра | |
| статус | активен / мёртв / не знаю | «не знаю» — стартовое значение [допущение] |
| время_последнего_обновления | игровое время | для UI, в логике не участвует |

**Метка поста:** квадрант, факт присутствия. Без статуса.

## Первый срез
Заглушка вместо [[Приём сигнала]]: один «сигнал_пойман» типа «сводка» с содержимым «в D4 шторм» и один со списком «ретранслятор в C2 активен». Заглушка вместо [[Время]] — фиксированный момент.

1. Сводка отображается рядом с сеткой; ни одна метка сама не появилась.
2. Клик по D4 с меткой «шторм» → в истории D4 одна запись с текущим временем заглушки.
3. Повторный клик по D4 с меткой «чисто» → в истории две записи, первая не пропала.
4. Клик по C2 «активен», затем «мёртв» → статус C2 = мёртв, прежнее значение нигде не хранится.

Признак готовности: история шторма растёт, ничего не теряя; статус ретранслятора — всегда только последнее значение; сводка ничего не проставляет автоматически.

## Связи
- [[Приём сигнала]] — принимает «сигнал_пойман» типа «сводка» с вложенным содержимым. Единственный вход информации о мире.
- [[Время]] — читает текущий момент, чтобы проштамповать время_наблюдения.
- [[Игровой цикл]] — отдаёт размер сетки из конфига партии.
- [[Проверка сигнала]] — не связаны явным стыком: перенос деталей на карту делает игрок кликом.
- [[Погода]], [[Структуры]], [[Журнал фактов]] — явно не связаны и связаны не будут: в этом весь смысл раздела.

## Открытые вопросы
- Точная механика «двух кликов»: порядок (сначала тип метки или сначала квадрант), как выглядит палитра типов.
- Как отображается сама пойманная сводка — список рядом с сеткой, всплывающее окно, что-то ещё.
- Показывается ли история шторма по квадранту списком, или на сетке копится иконка/счётчик наблюдений.
- Дают ли метки Постов механическую пользу в будущем, или остаются декоративными навсегда.
- Есть ли у ретрансляторов устойчивое имя/id, которое называет сводка, или сводка сразу говорит квадрантом — общий вопрос с [[Генератор эфира]] и [[Структуры]].
