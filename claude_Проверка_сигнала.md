# Проверка сигнала

## Суть
Платное действие игрока, которое превращает пойманный тюнером сигнал (id/частота/диапазон — всё, что даёт [[Приём сигнала]]) в раскрытые заявленные детали: откуда сигнал якобы пришёл, когда, каким путём, на каком расстоянии — плюс один сырой факт из истории [[Погода]]: был ли заявленный квадрант под штормом в заявленный момент. Не выносит вердикт «врёт/не врёт» сама — тег «точность», который уже лежит в записи сигнала у [[Генератор эфира]], эта система сознательно не читает и не показывает. Вывод «доверять или нет» игрок делает сам, опираясь на правило «сигнал не может прийти из-под шторма». Каждая проверка стоит и времени, и топлива.

## Как работает
1. Получает событие «сигнал_пойман» (id, частота, диапазон, тип) от [[Приём сигнала]] — **только для сигналов типа «обычный»**. Сводки сюда не приходят: они правдивы по построению и уходят прямо в [[Карта]]. Пойманный сигнал попадает в список «пойманных, но не проверенных»; проверка не запускается автоматически.
2. Игрок выбирает пойманный сигнал и запускает **проверку** — дискретное действие. Тратит стоимость_проверки_минуты минут (→ [[Время]]) и стоимость_проверки_топливо топлива (→ [[Генератор]]), оба [нужно значение].
3. По id читает у [[Генератор эфира]] полную запись: квадрант_источник, заявленное_расстояние, заявленный_путь, заявленная_метка_времени. Тег «точность» в этой же записи есть, но система его не запрашивает и не показывает — **[решено, вариант B]**.
4. Параллельно запрашивает у [[Погода]] историю: был ли заявленный квадрант_источник под штормом в заявленную метку времени. Погода отдаёт сырой факт — был / не был, без интерпретации.
5. Показывает игроку одним экраном: все заявленные детали + строку шторм-сверки как есть. Никакого «сигнал лжёт» или «сигнал подтверждён».
6. После показа сигнал помечается «проверен». **Повторный просмотр тех же деталей ресурсы не тратит. [принято, делегировано]** Игрок платит за добычу информации, а не за право посмотреть на неё второй раз; иначе он начнёт переписывать всё на бумажку, и это будет канцелярия, а не игра.
7. Что игрок делает с раскрытыми деталями дальше — записывает в рапорт, переносит на карту вручную, просто запоминает — не забота этой системы.
8. Фантомные сигналы [[Галлюцинации|Галлюцинаций]] проходят проверку неотличимо от настоящих: у них те же поля, заполненные синтетически, и шторм-сверка по ним отвечает так же честно. Система не должна уметь их различать.

## Контракт
- **Вход:** событие «сигнал_пойман» (только тип «обычный») от [[Приём сигнала]]; действие игрока «проверить сигнал X»; полная запись сигнала по id — читает по запросу у [[Генератор эфира]]; статус шторма в (квадрант, момент в прошлом) — читает по запросу у [[Погода]].
- **Выход:** раскрытые заявленные детали + сырой факт шторм-сверки — для UI; событие «потратить N минут» → [[Время]]; событие «потратить N топлива» → [[Генератор]]. Оба ресурса — ровно по одному разу на сигнал.
- **Владеет:** множеством id уже проверенных сигналов; стоимостью проверки в минутах и в топливе.
- **Не знает:** тег «точность» — принципиально не читает его, хотя технически мог бы; что игрок делает с деталями дальше; фантом это или настоящий сигнал.

## Данные

| Поле | Тип | Комментарий |
| :--- | :--- | :--- |
| стоимость_проверки_минуты | минуты | [нужно значение] |
| стоимость_проверки_топливо | число топлива | [нужно значение] |
| проверенные_id | множество | чтобы не списывать ресурсы дважды за один сигнал |

Отдельной таблицы для самого сигнала не заводим — запись уже данные [[Генератор эфира]], эта заметка их только читает.

## Первый срез
Заглушка вместо [[Приём сигнала]] — один «сигнал_пойман» (id=1, частота 42, диапазон «Военный», тип «обычный»). Заглушка вместо [[Генератор эфира]] — фиксированная запись по id=1 (квадрант_источник D4, расстояние 12, путь «через лес», метка времени 14:00, точность «ложь»). Заглушка вместо [[Погода]] — переключаемый ответ.

1. Проверка id=1 → списывается N минут и N топлива, на экране четыре заявленных поля плюс строка шторм-сверки.
2. Повторный запуск того же id → ресурсы не тратятся, детали показываются снова.
3. Переключить заглушку Погоды → строка шторм-сверки меняется, заявленные детали те же.

Признак готовности: ресурсы тратятся ровно один раз на сигнал, тег «точность» нигде не появляется в выводе, хотя в моке он выставлен в «ложь».

## Связи
- [[Приём сигнала]] — принимает «сигнал_пойман» для обычных сигналов, единственный вход в очередь проверки.
- [[Генератор эфира]] — читает полную запись сигнала по id; тег «точность» в ней есть, но не читается.
- [[Погода]] — читает статус шторма по (квадрант, момент в прошлом).
- [[Время]] — шлёт «потратить N минут».
- [[Генератор]] — шлёт «потратить N топлива».
- [[Карта]] — не связаны явным стыком: перенос раскрытых деталей на карту делает сам игрок кликом.

## Открытые вопросы
- Стоимость проверки в минутах и в топливе.
- Что происходит, если топлива не хватает даже на разовую трату — общий открытый вопрос [[Генератор]].
- Человекочитаемое описание «что случилось» помимо голых полей — вероятно собирается у [[Генератор эфира]] из типа_события и субъекта, но не решено.
- Может ли шторм-алиби когда-нибудь стать автоматическим вердиктом вместо сырого факта — не в первом срезе, возможное усложнение по итогам плейтеста.
