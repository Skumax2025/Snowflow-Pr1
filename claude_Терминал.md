# Терминал

## Суть
Единственный канал влияния игрока на мир, кроме настройки радио: свободный текст рапорта и его отправка в город. Здесь же живёт формула расхода на передачу и разовый дисклеймер. Терминал ничего не знает об исходе отправки — обратная связь по содержанию приходит игроку только позже, через [[Газета|Газету]].

## Как работает
1. **Набор рапорта.** Свободный ввод текста, любой объём, любое содержание. Само печатание времени не тратит — весь расход применяется одним куском в момент отправки.
2. **Отправка рапорта.** Точка невозврата, отменить нельзя. Клик «отправить» — финальное действие, без отдельного окна подтверждения.
3. При клике, **мгновенно и без ожидания ответа**: списываются время и топливо по формуле, синхронно уходит событие «рапорт_отправлен» → [[Парсер]], поле очищается, интерфейс сразу возвращается в простой. Никакого состояния загрузки — вызов [[Прокси к Gemini]] уходит в фон через Парсер, Терминал его не видит и не ждёт. **[принято, вариант 1]**
4. **Формула расхода** — две независимые пары коэффициентов одной формы:
   - время: `фикс_время + коэфф_время × длина_текста` → «потратить N минут» → [[Время]]
   - топливо: `фикс_топливо + коэфф_топливо × длина_текста` → «потратить N топлива» → [[Генератор]]
   Фикса делает батчинг выгодным по умолчанию, экстренная передача — просто лишний сеанс. Никаких режимов «обычный/срочный», один прайс.
5. **Пустой рапорт: кнопка «отправить» неактивна, пока поле пустое. [принято, делегировано]** Фикс-стоимость за нулевой текст — потеря без выбора внутри неё, тот же аргумент, которым убраны заправка генератора и «поесть» при нуле порций.
6. **Второй рапорт до обработки первого не блокируется.** [[Парсер]] стейтлесс, вызовы независимы, [[Город]] применяет вердикты в порядке прихода. Блокировка вернула бы состояние загрузки, от которого мы отказались. **[принято, делегировано]**
7. **Дисклеймер.** Показывается один раз за партию, перед самым первым открытием поля ввода — не перед первой отправкой. Называет **обе** стороны, куда уходит текст: во внешний сервис (Gemini) для разбора и, в части офтопика, в общую Базу аномалий, откуда после ручной модерации он может быть **показан другим игрокам** как голос в эфире. Точная формулировка — [открыто], за автором. Дальше в этой партии не появляется.

## Контракт
- **Вход:** сырой текст рапорта от игрока; действие «отправить».
- **Выход:** событие «рапорт_отправлен» (текст) → [[Парсер]]; событие «потратить N минут» → [[Время]]; событие «потратить N топлива» → [[Генератор]]. Все три — синхронно на одном клике, порядок между собой не важен.
- **Владеет:** текущим черновиком текста; флагом «дисклеймер_показан_в_партии»; коэффициентами обеих формул расхода; текстом дисклеймера.
- **Не знает:** об исходе обработки рапорта — успех, деградация, содержание claims/tone; о существовании [[Прокси к Gemini]]; о [[Город]]е, [[Журнал фактов|Журнале фактов]], [[Газета|Газете]], [[Фильтр аномалий|Фильтре аномалий]].

## Первый срез
Заглушки вместо [[Время]], [[Генератор]] и [[Парсер]] пишут входящие события в лог.

1. Клик «отправить» на тексте разной длины → в логе три события с корректными N по формуле.
2. Поле очищается сразу после клика, без задержки.
3. Кнопка «отправить» неактивна при пустом поле, событий не уходит.
4. Дисклеймер показывается ровно один раз за прогон — при первом открытии поля, не при втором.
5. Две отправки подряд без ожидания → оба «рапорт_отправлен» в логе, интерфейс ни разу не блокировался.

Признак готовности: числа в логе совпадают с формулой при трёх разных длинах; дисклеймер не дублируется; пустая отправка невозможна.

## Связи
- [[Время]] — шлёт «потратить N минут» при отправке.
- [[Генератор]] — шлёт «потратить N топлива» при отправке.
- [[Парсер]] — шлёт «рапорт_отправлен» (текст), единственный адресат содержимого.

## Открытые вопросы
- Коэффициенты и фиксы обеих формул, единица измерения длины текста.
- Точная формулировка дисклеймера — единственный пункт документа, где нужен авторский текст, а не число.
- Видит ли игрок ориентировочную стоимость отправки по мере набора, или узнаёт её только по факту списания.
