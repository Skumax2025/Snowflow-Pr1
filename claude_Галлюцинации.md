# Галлюцинации

## Суть
Механическое воплощение того, что низкий Рассудок [[Радист]]а делает мир вокруг ненадёжным ещё до того, как игрок сам ошибётся. Один общий триггер — Рассудок ниже собственного порога — запускает два параллельных проявления: в эфире появляются фантомные сигналы, неотличимые от настоящих на уровне тюнера и проверки, а в наушники начинают проникать голоса из Базы аномалий — офтопик-сообщения других игроков, поданные как чужое безумие. Оба эффекта усиливаются по мере того, как Рассудок проваливается глубже, и служат кульминацией финала при мёртвом городе.

## Как работает
1. Галлюцинации тикают по собственному расписанию [нужно значение] — сверяют момент партии с [[Время]], тик дёргает [[Игровой цикл]].
2. На каждом тике читают текущее значение Рассудка у [[Радист]]а по запросу.
3. Рассудок ≥ порог_критического_рассудка → оба потока молчат, тик ничего не делает.
4. Рассудок ниже порога → считается глубина провала и по ней масштабируется интенсивность обоих эффектов относительно базовых частот — формула [нужно значение], форма роста не решена.
5. С частотой фантомного сигнала для этого тика Галлюцинации шлют [[Генератор эфира]] явное событие «подмешать фантомный сигнал». Генератор эфира собирает **полностью синтетическую** запись: квадрант катается из сетки, тип события — из списка типов, заявленные детали генерируются теми же таблицами расхождения, что при «искажении», факт_источник пуст, диапазон катается из трёх. **Фантом не проходит проверки слышимости и глушения** — он звучит в голове, а не в эфире, и обязан появляться именно тогда, когда над вышкой шторм и всё остальное молчит. Запись ложится в тот же список, откуда её штатно читает [[Приём сигнала]]; ни Приём, ни [[Проверка сигнала]] не меняются, их контракт это предусматривал. **[решено, аудит]**
6. С частотой голоса аномалии для этого тика Галлюцинации запрашивают у [[Фильтр аномалий]] случайное аппрувленное, ещё не проигранное в этой партии сообщение и подают его как голос в эфире — отдельным каналом, не через тюнер и не через список сигналов. Если Фильтр отвечает «пусто» (база не наполнена или пул исчерпан) — Галлюцинации в этот тик просто молчат по этому каналу. Формат подачи (всплывающий текст / звуковая дорожка / нужно ли действие игрока) — [нужно значение], решение принадлежит этой заметке, а не Фильтру.
7. Ни один из двух эффектов не пишет факт в [[Журнал фактов]] — оба выдуманы, а Журнал обязан оставаться сырым логом того, что реально произошло.
8. Рассудок поднимается обратно выше порога → оба потока немедленно замолкают до следующего провала. Уже подмешанные фантомы из эфира не изымаются — они доживают свой TTL у [[Генератор эфира]].

**Побочный эффект, за которым стоит следить на плейтесте:** раз фантом обходит проверку шторма, во время шторма над вышкой эфир мёртв для всего, кроме галлюцинаций. Это готовая сцена, но и готовая подсказка: если игрок заметит закономерность, шторм станет надёжным индикатором «всё, что слышу сейчас — бред», и паранойя схлопнется вместо того, чтобы усилиться. **[открыто]**

## Контракт
- **Вход:** текущее значение Рассудка — читает у [[Радист]]а по запросу на каждом тике; момент партии от [[Время]]; вызов тика от [[Игровой цикл]].
- **Выход:** явное событие «подмешать фантомный сигнал» → [[Генератор эфира]]; запрос «голос из Базы аномалий» → [[Фильтр аномалий]] и приём ответа (текст или «пусто»); сам голос — тому, кто его подаёт игроку.
- **Владеет:** порогом_критического_рассудка; расписанием собственного тика; базовыми частотами обоих эффектов и коэффициентом нарастания интенсивности; форматом подачи голоса игроку; списком id сообщений Базы аномалий, уже проигранных за партию.
- **Не знает:** как [[Генератор эфира]] формирует диапазон, частоту и заявленные детали фантома — только просит; содержание сообщений Базы аномалий заранее; что игрок делает с пойманным фантомом или услышанным голосом; про [[Журнал фактов]] — оба эффекта в него принципиально не пишут.

## Данные

| Поле | Тип | Комментарий |
| :--- | :--- | :--- |
| порог_критического_рассудка | значение шкалы Рассудка (0–100) | [нужно значение] |
| расписание_тика | минуты | [нужно значение] |
| базовая_частота_фантомного_сигнала | вероятность за тик | [нужно значение] |
| базовая_частота_голоса_аномалии | вероятность за тик | [нужно значение] |
| коэффициент_нарастания | множитель от глубины провала | [нужно значение], форма роста не решена |
| формат_подачи_голоса | текст / звук / текст+действие | [нужно значение] |
| список_id_проигранных_сообщений | состояние партии | служебный список, не таблица данных |

Список id заказанных фантомов отдельно не хранится: после отправки события Галлюцинации о судьбе фантома ничего не знают, им владеет [[Генератор эфира]].

## Первый срез
Заглушка вместо [[Радист]]а — переключаемое значение Рассудка. Заглушка вместо [[Генератор эфира]] — лог принятых событий. Заглушка вместо [[Фильтр аномалий]] — фиксированный список из трёх тестовых сообщений плюс ответ «пусто», когда они кончились.

1. Рассудок выше порога → ни один тик не порождает ни одного события.
2. Опустить ниже порога → с базовой частотой приходят оба типа событий.
3. Опустить ещё глубже → частота обоих заметно растёт против шага 2.
4. Поднять обратно выше порога → оба потока немедленно останавливаются.
5. Прогнать голос несколько раз подряд на пуле из трёх → три разных сообщения без повторов, четвёртый запрос возвращает «пусто», Галлюцинации молчат по этому каналу и не падают.

Признак готовности: оба эффекта включаются и выключаются строго по порогу, интенсивность растёт с глубиной провала, повторов голоса нет, пустая база не ломает тик.

## Связи
- [[Радист]] — читает текущее значение Рассудка по запросу.
- [[Время]] — читает момент партии; [[Игровой цикл]] дёргает тик.
- [[Генератор эфира]] — шлёт «подмешать фантомный сигнал».
- [[Фильтр аномалий]] — запрашивает случайное аппрувленное непроигранное сообщение, получает текст или «пусто».
- [[Приём сигнала]], [[Проверка сигнала]] — не связаны напрямую: фантом попадает к ним обычным путём и специально не отличается.
- [[Журнал фактов]] — явно не связаны: ни один эффект туда не пишет.

## Открытые вопросы
- Порог_критического_рассудка, расписание тика, базовые частоты обоих эффектов, коэффициент и форма нарастания.
- Формат подачи голоса из Базы аномалий игроку.
- Не превращается ли шторм в подсказку «сейчас всё враньё» — проверить на плейтесте, см. выше.
- Лимит одновременно висящих в эфире фантомных сигналов, если понадобится.
- Хватает ли одного порога на оба эффекта, или голосам нужен свой, более низкий.
