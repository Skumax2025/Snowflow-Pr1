# CONTRACTS.md — таблица контрактов Snowflow

Собрано на этапе 0 по мастер-концепту и 26 заметкам ГДД. Источник правды — заметки;
мастер-концепт главнее по межсистемным связям и словарю имён.

Колонка «Модуль» — файл реализации. Имена событий в коде — канонические строки из
словаря мастер-концепта (раздел 13), константы собраны в `src/core/events.ts`.

## 5. Непарные связи и расхождения, найденные на этапе 0

Все занесены в DECISIONS.md; здесь — сводка.

| № | Что | Тип | Решение |
| :--- | :--- | :--- | :--- |
| 1 | Стенд шлёт Времени «потратить N минут», но во «Входе» Времени Стенд не указан | контракт | добавлен как отправитель |
| 2 | Фильтр аномалий ждёт «момент старта партии от Игрового цикла», у Игрового цикла в связях его нет | контракт | добавлен в инициализацию |
| 3 | «потратить N минут» напрямую Времени vs требование лупа прогнать интервал шагами | контракт | доставка через чанкер лупа; Время по-прежнему только прибавляет |
| 4 | Мастер 6.3 «атака обнуляет Целостность» vs Структуры п.3 «N вычитается» | конфликт | принята заметка Структуры (вычитание) |
| 5 | Газета: «по запросу либо событием "выпуск_готов"» — не решено | дыра | выбрано чтение по запросу + событие-уведомление |
| 6 | Генератор: что делать с дискретной тратой при нехватке топлива | дыра | списывается сколько есть, действие проходит |
| 7 | Финал: собственный тик или тик Газеты | дыра | собственный тик с тем же интервалом |
| 8 | Заметки «База аномалий» нет отдельным файлом | не дыра | по мастеру 11.2 это одна заметка с Фильтром аномалий |
| 9 | Приём сигнала отдаёт «приём_заблокирован» — получателя-системы нет | не дефект | потребитель — UI |
| 10 | Стенд: без потока «вердикт_рапорта» петля Доверие→Снабжение не крутится | дыра | добавлен опциональный синтетический поток рапортов, по умолчанию выключен |
